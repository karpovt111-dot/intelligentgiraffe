# 🦒 Интеллектуальный жирафик

Платформа для проведения олимпиад и конкурсов для школьников. Полный стек: **FastAPI** (backend) + **Jinja2** (шаблоны) + **SQLite** (база данных). Без внешней почты, без OAuth, без сбора паспортных данных — только логин, e-mail, пароль и класс.

---

## ✨ Возможности

### Аккаунты
- **Регистрация** на отдельной странице `/register`: имя пользователя, e-mail, пароль и **класс (1–11)**.
- **Вход** на отдельной странице `/login`: по логину или e-mail.
- **Выход** — POST `/logout`.
- **Сессия** — подписанные http-only cookies (`itsdangerous`), срок жизни 7 дней.
- **Пароли** хешируются `PBKDF2-HMAC-SHA256` (260 000 итераций) через стандартный `hashlib` — без `passlib`, стабильно работает на Python 3.13/3.14.

### Шапка сайта
- Слева — название «Интеллектуальный жирафик» с эмодзи 🦒.
- Справа — кнопка **«Зарегистрироваться»** (для гостя) или **имя пользователя + «Выйти»** (для авторизованного).
- Ниже — навигация: **Олимпиады**, **Конкурсы**, **Публикации**, выпадающее меню **Другое** (Сертификаты, Подготовка к олимпиадам, Положения мероприятий).

### Олимпиады с системой классов
- В папке `olympiads/` лежат HTML-файлы с именами вида `{предмет}_{класс}.html` — например, `math_5.html`.
- Список олимпиад формируется автоматически из содержимого папки.
- Название и бейдж класса генерируются из имени файла: `math_5.html` → **«Математика — 5 класс»**.
- **Правило доступа**: участник может проходить олимпиады **своего класса и старше**. Олимпиады для младших классов отображаются, но заблокированы (🔒) с пояснением.
- Прямой переход по URL заблокированной олимпиады → редирект обратно в список с сообщением об ошибке.

### Конкурсы
- Работают по тому же принципу, но **без ограничения по классу** — доступны всем авторизованным пользователям.
- Файлы лежат в папке `courses/`.

### Защита
- Без авторизации нельзя открыть ни одну олимпиаду или конкурс — редирект на `/login?next=...`.
- После входа пользователь возвращается к тому материалу, который пытался открыть.
- Защита от path traversal при отдаче HTML-файлов.
- Блокировка открытых редиректов в параметре `next`.

## 🚀 Установка

```bash
# 1. Клонируйте/распакуйте проект
cd giraffic

# 2. (опционально) создайте виртуальное окружение
python -m venv .venv
source .venv/bin/activate          # Linux/macOS
# .venv\Scripts\activate           # Windows

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Создайте .env и задайте SECRET_KEY
echo "SECRET_KEY=сгенерируйте_случайную_строку" > .env
```

Сгенерировать `SECRET_KEY`:

```bash
python -c "import secrets; print(secrets.token_urlsafe(64))"
```

Скопируйте вывод в `.env`.

## ▶️ Запуск

### Шаг 1. Сгенерировать олимпиады (только при первом запуске)

```bash
python generate_olympiads.py
```

Скрипт создаст **41 файл**:



## 📚 Встроенные олимпиады

Скрипт `generate_olympiads.py` создаёт олимпиады по пяти предметам:

| Предмет | Классы | Кол-во |
|---------|--------|--------|
| **Математика** | 1–11 | 11 |
| **Русский язык** | 1–11 | 11 |
| **Английский язык** | 2–9 | 8 |
| **Физика** | 7–11 | 5 |
| **Информатика** | 4–9 | 6 |
| **Итого** | | **41** |

Вопросы для каждого класса:
- **Математика** — генерируются программно под сложность класса (сложение/вычитание в 1–2 классе, умножение в 3–4, степени и корни в 9–11).
- **Русский язык** — банк из 15 заданий (падежи, части речи, орфография, синонимы).
- **Английский язык** — банк из 15 заданий (лексика, времена, артикли, перевод).
- **Физика** — банк из 15 заданий (силы, скорость, плотность, электричество).
- **Информатика** — банк из 15 заданий (биты, системы счисления, устройства, алгоритмы).

### Как работает ограничение по классу

У каждого пользователя при регистрации сохраняется `grade` (1–11). При открытии списка олимпиад сервер:

1. Парсит имя файла `math_5.html` → `subject="math"`, `grade=5`.
2. Сравнивает `grade` олимпиады с `grade` пользователя.
3. Если **олимпиада для более младшего класса** (5-классник открывает олимпиаду для 4 класса) → карточка помечается как 🔒 и кликнуть на неё нельзя.
4. Если **для своего или старшего** → карточка кликабельна и олимпиада открывается.

**Пример:** пользователь с классом `5`:
- ✅ `math_5.html`, `math_6.html`, `math_11.html` — доступны
- 🔒 `math_1.html` … `math_4.html` — заблокированы

## 📝 Как добавить свои олимпиады и конкурсы

### Своя олимпиада
Поместите `.html` файл в `olympiads/` с именем **`{предмет}_{класс}.html`**:

```
olympiads/math_5.html       → Математика — 5 класс
olympiads/russian_9.html    → Русский язык — 9 класс
olympiads/physics_11.html   → Физика — 11 класс
```

Поддерживаемые slug'и предметов: `math`, `russian`, `english`, `physics`, `informatika`.  
Для других предметов название будет взято из имени файла.

Файл **не** должен содержать внешних зависимостей — все стили и скрипты — инлайн или с абсолютными URL.

### Свой конкурс
Просто положите `.html` в `courses/` с любым именем:

```
courses/creative_writing.html  → Creative Writing
```

Ограничения по классу для конкурсов **не применяются**.

### ❌ Не нужно перезапускать сервер
Списки читаются из папок на каждый запрос, поэтому новые файлы появляются сразу после обновления страницы.

## 🛡️ Безопасность

1. **Смените `SECRET_KEY`** в `.env` перед продакшеном. Это ключ подписи cookies.
2. Cookies — `httponly=True`, `samesite="lax"`. Для HTTPS добавьте `secure=True` в `main.py`.
3. Пароли не хранятся в открытом виде — только хеш PBKDF2-HMAC-SHA256.
4. Защита от path traversal при отдаче HTML-файлов (`serve_file`).
5. Открытые редиректы в `next` блокируются (`safe_next`).
6. Для продакшена — HTTPS-прокси (nginx/Caddy) перед Uvicorn и запуск без `--reload`.

## 🧪 Тестовый сценарий

1. Откройте `/` → нажмите **«Зарегистрироваться»**.
2. Введите имя, e-mail, пароль и **класс 5** → сразу залогинились.
3. Перейдите в **«Олимпиады»** — видны 41 карточка, у всех бейдж класса.
4. Олимпиады для 1–4 классов — 🔒 заблокированы с подписью «Только для 4 класса и младше».
5. Олимпиады для 5–11 классов — открываются, внутри тест с проверкой ответов.
6. Попробуйте открыть заблокированную олимпиаду через URL напрямую → редирект в список с сообщением.
7. **Выйти** → попробовать открыть любую олимпиаду → редирект на `/login`.
8. Войти → вернуться к нужной олимпиаде.

## ❗ Частые проблемы

| Проблема | Решение |
|----------|---------|
| `uvicorn: command not found` | Активируйте venv: `.venv\Scripts\activate` (Win) / `source .venv/bin/activate` (Unix) |
| `ModuleNotFoundError: No module named 'fastapi'` | `pip install -r requirements.txt` |
| `Address already in use` | Порт 8000 занят: `--port 8001` |
| `TemplateNotFound` | Терминал открыт не в папке `giraffic/` |
| В списке олимпиад пусто | Запустите `python generate_olympiads.py` |
| Олимпиада не открывается | Проверьте, что вы вошли и что класс олимпиады ≥ вашего |
| `SMTP` / `passlib` в трейсбеке | Их больше нет в проекте — удалите старые импорты и обновите `requirements.txt` |
